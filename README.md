# สุขภาพบ้านบึงสว่าง · รพ.สต.บ้านแดง

เว็บค้นหาข้อมูลสุขภาพจากรายงานมาตรฐาน [HDC จังหวัดขอนแก่น](https://hdc.moph.go.th/kkn/public/main)
ของ **บ้านบึงสว่าง หมู่ 11 ต.บ้านเหล่า อ.บ้านฝาง จ.ขอนแก่น** และ **รพ.สต.บ้านแดง (13896)** ย้อนหลัง 5 ปีงบประมาณ
พร้อมตัวเลขเทียบ อ.บ้านฝาง และ จ.ขอนแก่น

- ตัวเลขดึงจาก API ของหน้าเว็บ HDC โดยตรง (ชุดเดียวกับที่เห็นบนเว็บ HDC เมื่อกรอง อำเภอ บ้านฝาง / ตำบล บ้านเหล่า)
- GitHub Actions ดึงข้อมูลวันละ 2 รอบ (06:00 และ 18:00 น.) แล้วเผยแพร่หน้าเว็บผ่าน GitHub Pages

| ไฟล์ | หน้าที่ |
|---|---|
| `fetch_hdc.py` | ดึงตารางรายงานจาก HDC (รายหมู่บ้าน / รายหน่วยบริการ / รายอำเภอ / จังหวัด) |
| `fetch_opendata.py` | รายการรายงานทั้งหมดของ HDC (catalog) และเครื่องมือร่วม |
| `hdc_render.py` | อ่านหัวตารางและสูตรคอลัมน์ของ HDC |
| `build_site.py` | สร้าง `site/data.js` จากฐานข้อมูล |
| `site/` | หน้าเว็บ (ไฟล์ static) |
